# Frontend Challenges

This repo is a collection of challenges for students and curious learners.

## Setup

1. [Install git](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)
1. Clone repo

```sh
git clone https://github.com/thepeaklab/frontend-challenges.git
```

## Overview

The challenges may be solved in the following order.
For advanced learners, the introduction may be skipped.

| No. | Category                |
| --- | ----------------------- |
| 1   | [html_css](./html_css/) |
| 2   | [js](./js/)             |
| 3   | [react](./react/)       |

### Web App: the peaklab academy

All challenges can also be solved directly in the browser: with an editor, live preview and automated feedback. See [web/README.md](./web/README.md) for details and local development (`./dev.sh setup && ./dev.sh start`).
